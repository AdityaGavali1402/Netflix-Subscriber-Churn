# Part 1: Exploratory Data Analysis (EDA)

## Overview
This part focuses on cleaning and exploring the Netflix subscriber churn dataset to identify patterns in customer behavior and churn.

## Objectives
- Inspect the dataset and identify data quality issues.
- Handle missing values, duplicates, inconsistent formats, and outliers.
- Perform univariate and bivariate analysis.
- Analyze churn patterns based on customer satisfaction, subscription plans, and engagement.

## Files
- `Netflix_Churn_EDA.ipynb` — EDA notebook.
- `Netflix_Churn_EDA.pdf` — EDA report.

## Tools Used
Python, Pandas, NumPy, Matplotlib, Seaborn, and Jupyter Notebook.
